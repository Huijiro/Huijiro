### whoami

I'm an engineer at [Oz is Home](https://ozishome.com/), a full-stack platform for
AI agents. I work mostly on the CLI, dev mode, build pipeline, and framework
plumbing. The goal is simple: starting an agent should take one command, not a
Friday afternoon.

Right now I'm leading our next major platform rewrite. That means retiring the
old runtime, building a framework-agnostic pipeline, adding proper support for
the frameworks people want to use, and hunting down dev mode race conditions.

Outside work, I write Neovim plugins, Pi extensions, and games I will almost
certainly never finish. If something should exist and doesn't, I'll probably
build it.

### software people use

- **[YaYeet](https://github.com/Huijiro/YaYeet)** installs and runs [Voices of the Void](https://votv.dev/) on Linux through Wine or Proton. It handles game versions, runners, updates, and the usual Linux gaming ceremony.
- **[blink-cmp-supermaven](https://github.com/Huijiro/blink-cmp-supermaven)** is a Supermaven source for [blink.cmp](https://github.com/Saghen/blink.cmp). It is also the one repo of mine that strangers star.
- **[tmux-nav.nvim](https://github.com/Huijiro/tmux-nav.nvim)** handles Neovim and tmux pane navigation. Every existing plugin had one feature too many.

### Pi extensions

I build tools for [Pi](https://github.com/earendil-works/pi-coding-agent), an extensible coding agent.

- **[click](https://github.com/Huijiro/click)** adds persistent SQLite memory, FTS5 search, and automatic context injection.
- **[pi-lsp](https://github.com/Huijiro/pi-lsp)** shows inline LSP diagnostics when Pi reads a file and includes a standalone diagnostics tool.
- **[pi-fireworks](https://github.com/Huijiro/pi-fireworks)** adds Fireworks AI as a provider.
- **[nvim-pi](https://github.com/Huijiro/nvim-pi)** runs Pi inside Neovim.
